# Vekku

Vekku is an intelligent digital knowledge base that uses AI to help you organize and categorize your thoughts, projects, and ideas.

## Project Structure

- **[web (Frontend)](./web)**: A modern React application built with TypeScript, Tailwind CSS, and Shadcn UI, featuring a glassmorphism design.
- **[backend (Backend)](./backend)**: A high-performance Bun runtime service utilizing Neon (PostgreSQL), Drizzle ORM, and Cloudflare AI for semantic analysis.
- **[docs](./docs)**: Comprehensive documentation including user guides and technical architecture details.

## Core Features

- **Semantic Tagging**: Automatically suggests tags based on content meaning.
- **Concept Discovery**: Identifies new potential keywords and concepts as you write.
- **Performance Optimized**: Built for speed with Bun and efficient caching strategies.
- **Responsive Design**: Beautiful liquid-glass UI that works across all devices.
